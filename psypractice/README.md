# PsyPractice — учебная демонстрационная веб-платформа

Рабочий прототип по ТЗ PsyPractice (10 октября 2026): стартовая страница, 6 сценариев виртуального клиента, анализ текстовых консультаций, 9 карточек психологических техник, история и профиль. Адаптивен для компьютера и телефона.

## Быстрый запуск

Установите Node.js 20+; затем в папке проекта выполните:

```bash
npm start
```

Откройте http://localhost:3000.

**Важно:** без AI-ключа сайт работает в явно обозначенном демонстрационном режиме: ответы виртуального клиента преднаписаны, AI-оценки отсутствуют. Кнопки, сохранение истории, сценарии и навигация работают.

## Включить реальный ИИ

Установите переменную окружения `OPENAI_API_KEY` на сервере и перезапустите приложение. По желанию укажите `OPENAI_MODEL` (по умолчанию `gpt-4.1-mini`). Ключ **никогда не размещать в frontend**.

Linux / macOS:

```bash
OPENAI_API_KEY='your_key' npm start
```

PowerShell:

```powershell
$env:OPENAI_API_KEY='your_key'; npm start
```

Используется OpenAI Chat Completions API для анализа, живого диалога и обратной связи. Реальный API платный в зависимости от тарифа.

## Публикация

Проект запускается как Node.js веб-сервер, слушает переменную `PORT` и адрес `0.0.0.0`. Подходит для Render / Railway / другого Node.js хостинга. Загрузите проект в GitHub, создайте Web Service, команда запуска `npm start`, добавьте переменную OPENAI_API_KEY в настройках хостинга. Затем сервис выдаст публичный URL. **Это не проект для статического Vercel без дополнительных серверных настроек.**

## Ограничения и честные обозначения

- Локальный профиль и результаты сохраняются через localStorage, без настоящей регистрации / изоляции данных на сервере. Нельзя считать это готовой многопользовательской системой.
- Реальные записи клиентов и их персональные данные использовать нельзя до доработки доступа, согласий, хранения, удаления, журнала действий и проверки требований законодательства РК.
- Нет полноценного кабинета преподавателя, аудио/видео и подтверждённой экспертами точности оценок.
- Демонстрационный отчёт **не является AI-оценкой**, что отражено в интерфейсе.
- Для полноценного MVP понадобится Supabase Auth, PostgreSQL, row-level security, безопасное хранение, ограничения API-запросов и тестирование качества.

Разработано как прототип для презентации в классе, а не клинический сервис.
